# Art and assets

All of the web app's artwork is either original to this project and generated by scripts in the repository, or derived from public-domain sources, so every asset can be rebuilt and every licence is known. The fonts are open-source.

There are two generations of art:

1. The **base set** from the art pipeline in [`web/tools/art/`](../web/tools/art): the playing-card faces, which the current interface uses, plus card backs, table materials, avatars, a room panorama and UI marks made for an earlier 3D casino-table interface.
2. The **Dacha kit** in `web/public/assets/dacha/`, built by the tools in [`concepts/dacha/tools/`](../concepts/dacha/tools) for the current interface: portraits, brand marks, card backs, illustrations, props, icons, the table, design tokens and fonts.

## The card faces

The faces are built from the *English pattern* SVG playing cards by **Dmitry Fomin** on Wikimedia Commons, which are dedicated to the public domain under CC0 1.0. The pipeline, in [`web/tools/art/cards.py`](../web/tools/art/cards.py), for each card:

1. parses and sanitises the downloaded SVG (no scripts or external references are allowed);
2. recolours the source's flat palette to a refined print palette;
3. in Chromium (Playwright), removes the source's white base and corner indices and enlarges the ace pip; the ace of spades gets an original ornamental design;
4. lays the art onto a 512 × 716 face (the 2.5 : 3.5 poker proportion) with new serif indices;
5. composites it onto procedurally generated ivory card stock.

High-resolution versions are rasterised from the vector sources at the target size, and the paper texture is generated at native resolution rather than scaled up. The four-colour variant recolours clubs and diamonds.

[`web/tools/art/fetch_cards.py`](../web/tools/art/fetch_cards.py) downloads the 36 source files. It confirms through the Commons API that each file is licensed CC0, treats the downloads as untrusted data (they are only parsed as SVG text, never executed), and checks each against the SHA-256 hash pinned in [`web/tools/art/sources.json`](../web/tools/art/sources.json).

## Rebuilding the base set

```bash
# Requirements: numpy, Pillow, fonttools, Playwright with Chromium, and the fonts
# EB Garamond and URW P052 (Ubuntu: fonts-ebgaramond-extra, fonts-urw-base35)
uv pip install --python .venv/bin/python numpy pillow fonttools playwright
.venv/bin/python -m playwright install chromium

.venv/bin/python web/tools/art/build_all.py                  # everything (1x and @2x/@3x)
.venv/bin/python web/tools/art/build_all.py --scales 2,3     # only the hi-res faces and backs
.venv/bin/python web/tools/art/build_all.py --manifest-only  # re-index existing files
```

The source SVGs are downloaded once into the directory named by `DURAK_ART_SRC` (by default a directory under the system's temporary directory) and verified before use. Every random texture is seeded and generated in the frequency domain, so the outputs are deterministic and tile seamlessly. `build_all.py` writes `manifest.json` and `LICENSES.md` next to the assets.

| Module | Produces |
|---|---|
| `cards.py`, `fetch_cards.py` | card faces, thumbnails and the four-colour deck |
| `backs.py` | four card backs with 180° rotational symmetry, like real backs |
| `materials.py` | tileable table materials (felts, walnut, leather, brushed brass) with normal maps |
| `env.py` | the room panorama |
| `avatars.py` | the earlier portraits |
| `ui.py` | gold suit emblems, the logo monogram, chips |
| `common.py`, `svgkit.py` | seeded noise, Chromium rendering, a small procedural SVG toolkit |

## Rebuilding the Dacha kit

The kit is assembled from the Dacha design concept:

```bash
# 1. Serve the concepts (build_kit.py renders through this server)
.venv/bin/python -m http.server 8765 --bind 127.0.0.1 --directory concepts &

# 2. Table and floor renders (numpy + Pillow); writes concepts/dacha/img/
.venv/bin/python concepts/dacha/tools/bake.py

# 3. Assemble the kit into web/public/assets/dacha/
.venv/bin/python concepts/dacha/tools/build_kit.py
```

- `bake.py` renders the oval card table seen from directly above: worsted baize lit by a soft overhead light, a bent-wood rail with a brass bead and a padded leather armrest, contact shadows, an optional braided rag rug, and a tileable pine floor.
- `kit_art.py` draws the wordmarks, the portrait frame, the card backs and the game-over illustrations. All lettering is converted to outlines of Playfair Display, so the SVGs need no fonts.
- `build_kit.py` copies and minifies the SVG sources from `concepts/dacha/art/` (portraits and props), writes the icon set, renders WebP versions with Chromium, and writes `manifest.json` and `tokens.css` with the palette, typography and shadows.

`concepts/assets` is a symbolic link to `web/public/assets`, so the concept pages and the kit tools see the same files as the app.

## Design concepts

[`concepts/`](../concepts) holds four static, clickable design concepts of the same moment (a five-player game in which you defend against an 8♦), each with a title, lobby and table page for desktop and phone, the tools that made its art, and screenshots in `shots/`. [`concepts/index.html`](../concepts/index.html) is a gallery of all four.

| Concept | Style |
|---|---|
| Arcade | bright mobile-game style: teal felt, chunky glossy buttons, character avatars with level badges, big-index cards |
| Atelier | elegant flat minimalism: warm paper, no felt, a single cobalt accent, refined typography, a card tracker; with a dark mode |
| **Dacha** | warm illustrated Russian folk-art world: sunlit embroidered tablecloth, samovar and tea, Gzhel card backs, woodcut-style wordmark, illustrated characters |
| Tabletop | a realistic table seen straight down, like a flagship poker app: baize, leather rail, printed-card shadows, frosted interface |

The web app combines the Dacha world with the Tabletop concept's oval table. To browse the concepts, run `.venv/bin/python -m http.server 8765 --directory concepts` and open <http://localhost:8765/>.
